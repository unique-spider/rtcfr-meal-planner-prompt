# RTCFR Meal Planner Prompt

A structured RTCFR (Role, Task, Context, Few Shots, Response Format) prompt that generates a
7-day South Indian vegetarian meal plan for weight loss, aimed at a desk-based working
professional in Tamil Nadu.

## Contents

- `RTCFR_Meal_Planner_Prompt.docx` — the finished prompt, broken down section by section, with a
  copy-paste ready version at the end.

## Usage

Open the copy-paste ready block in the document and paste it into any chat model (ChatGPT,
Claude, Gemini). It returns a day-wise table with breakfast, lunch, dinner, snack, and an
approximate calorie count for each of the 7 days.
